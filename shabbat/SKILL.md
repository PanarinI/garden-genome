Ты проводишь ШАББАТ — выдох проекта с живым контекстом (правила — в `CLAUDE.md` проекта).
Седьмой день: остановиться, взглянуть на сделанное, увидеть «что хорошо». Цель — перенести
знание из этой сессии в файлы-столпы, чтобы следующая сессия продолжила дёшево и без потерь.

# Когда уместно
Закончен осмысленный кусок (и он работает/проверен); перед паузой или концом дня; когда
сессия разрослась. НЕ посреди недоделанной задачи — сперва доведи или явно отметь как «в работе».

# Шаг 0. Определи проект и назови его вслух
Выдыхает тот проект, в котором шла сессия. **Назови цель одной строкой** («выдыхаю `<проект>`»)
и дай поправить, ПРЕЖДЕ чем писать в файлы. Если сессия задела НЕСКОЛЬКО проектов — перечисли ВСЕ затронутые и выдохни каждый по очереди
(Шаги 1–6 на каждый), не выбирая один в ущерб другим; напоминание про «git» (Шаг 7) — один раз в конце. Затем для
каждого прочитай `CLAUDE.md`, `STATE.md`, `DECISIONS.md` и органы по полному пути. Нет столпов — проект ещё не «зарождён»: предложи сначала `/seed`, не выдумывай столпы.

# Шаг 1. Обнови `STATE.md`
Перепиши «где мы сейчас» + следующие шаги. STATE — снимок настоящего, не дневник:
неактуальное убирай.

# Шаг 2. Допиши `DECISIONS.md` (если были решения)
Только НЕОЧЕВИДНЫЕ «почему» — то, что не выводится из самого результата. Дописывай, не переписывай.

# Шаг 3. Поправь `CLAUDE.md` (если изменилось)
Поменялись суть / правила / архитектура / карта столпов — отрази. Иначе не трогай.

# Шаг 4. Пересмотри карту органов
Родить новый орган (инфа повторяется и не влезает) · слить дубли · **убрать** мёртвое.
Держи столпы как сигнал, не лог (законы курирования).

# Шаг 5. Итог сессии
Кратко, по-человечески, перечисли что сделано за сессию.

# Шаг 6. Передача в новую сессию
Выдай готовое **«первое сообщение для НОВОЙ сессии»**: что прочитать
(`CLAUDE.md` → `STATE.md` → `DECISIONS.md` → нужные органы) и какой следующий шаг.
Напомни: дальше лучше начать свежую сессию — контекст восстановится из файлов, а не из истории чата.
**Тело послания живёт в STATE** («Следующий шаг», можно готовой триггер-фразой) — чат эфемерен,
STATE вечен; в чат выдаётся лишь копия для руки (закладка — sinai/DECISIONS 07-02). Вставлять его
руками автору НЕ нужно: утренний boker возьмёт нить из STATE сам.

# Шаг 7. Напомни про «git» — сам НЕ коммить
Коммит больше НЕ входит в шаббат (решение автора 2026-07-02: рефлексия и сохранность — разные
педали; см. sinai/DECISIONS). Заверши выдох одной строкой: «столпы записаны — скажи **git**,
сниму слепок сада». Слово «git» = `bash ~/PycharmProjects/garden-meta/tools/gitall.sh`
(ВСЕ репо сада: add → commit → push + отчёт; из любой сессии; `--dry` — примерка).
У тронутого проекта нет репо → отметь как открытый узел, не молчи (новые репо — приватные по умолчанию).
