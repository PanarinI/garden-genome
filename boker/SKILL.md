ПУЛЬТ (скрипт читает живые файлы — токены на пересказ не тратим); твоя работа — ведро, нить, дела.

# Две двери — сначала реши, какой бокер (правило корневого `CLAUDE.md`)
- **Проект НЕ назван / просто «boker»** → **ПОЛНЫЙ бокер**: все шаги ниже. Это общий взгляд на сад
  (пульт-панорама + нить-триаж «за что взяться») + садовая уборка дня (разбор ведра · дневник дней).
- **Проект назван** (арг скилла · «работаем над X» · сессия уже в папке проекта) → **УЗКИЙ бокер**:
  освежи пульт (Шаг 1 — скрипты, дёшево, для глаз автора), в ведро **загляни лишь на записи про этот
  проект**, и сразу **Шаг 3** по нему. **Дневник дней НЕ пиши и ведро целиком НЕ разбирай** — это
  садово-ГЛОБАЛЬНАЯ работа (один писарь в день): две проектные сессии в один день столкнулись бы на
  общем дневнике/ведре (страж свежести поймает, но это лишняя возня). Их делает только полный бокер.
  (Почему — `sinai/DECISIONS.md` 07-07.)

# Шаг 1. Обнови и открой пульт + щёлкни день

```
python3 ~/PycharmProjects/deux-ex-machina/gen_pult.py && open ~/PycharmProjects/deux-ex-machina/pult.html
python3 ~/PycharmProjects/garden-chronicle/dni/snimok_dnya.py
```

Пульт сам читает все `*/STATE.md` + дела + ведро и показывает автору: тепло (свежесть STATE) · вес ·
пульс кода · **⚠ недовыдохнутость** (работа обогнала выдох) · насущные дела · ведро.
Второй скрипт — **дневник дней** (орган `garden-chronicle/dni/`): щёлкает утренний снимок всех STATE
и печатает диф со вчерашнего утра. Диф не пуст → **(только ПОЛНЫЙ бокер)** допиши в `garden-chronicle/dni/DNI.md` запись
«День <пред. снимок> → <сегодня>»: 3–8 строк человеческим языком, только затронутые проекты
(сигнал дня, не пересказ STATE). Дифа нет (первый кадр / тихий день) → ничего не пиши.
**MAP при бокере НЕ читай** — он принадлежит педали «атлас/обход» (машинный конспект для вдоха +
перепись спящих без STATE + хроника обходов). Скрипт упал → fallback: `ls -t */STATE.md`.
