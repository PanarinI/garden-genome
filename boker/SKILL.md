# Шаг 1. Обнови и открой пульт

```
python3 ~/PycharmProjects/deux-ex-machina/gen_pult.py && open ~/PycharmProjects/deux-ex-machina/pult.html
```

Пульт сам читает все `*/STATE.md` + дела + ведро и показывает автору: тепло (свежесть STATE) · вес ·
пульс кода · **⚠ недовыдохнутость** (работа обогнала выдох) · насущные дела · ведро.
**MAP при бокере НЕ читай** — он принадлежит педали «атлас/обход» (машинный конспект для вдоха +
перепись спящих без STATE + хроника обходов). Скрипт упал → fallback: `ls -t */STATE.md`.

# Шаг 2. Разбор ведра

`garden-meta/INBOX.md`: пусто под линией → дальше. Есть записи → выполни ритуал «разбор ведра»
(закон — в `garden-meta/CLAUDE.md`): каждую разложи по дому и скажи куда; разобранное →
`INBOX-archive.md` (append, НЕ удалять); INBOX оставь чистым.

# Шаг 3. Нить и дела

Активная нить = свежайший `*/STATE.md` (`ls -t` — даты, не чтение всех) → прочитай столпы ТОЛЬКО её
(капсула). Послание прошлого шаббата — это «Следующий шаг» в STATE (закладка, sinai/DECISIONS
07-02): вставлять его руками автору не нужно. Затем `garden-meta/dela.md`: ⭐ и близкие дедлайны —
напомни словами.
